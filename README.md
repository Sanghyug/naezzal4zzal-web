## AI 서버 설정

.env.example은 설정 이름 안내입니다. 키를 소스코드나 VITE_ 변수에 넣지 마세요. 실제 키는 배포 서버의 환경변수에만 설정합니다.

- OPENAI_API_KEY: 서버에서만 사용하는 키
- OPENAI_VISION_MODEL: 기본 gpt-5.4
- ALLOWED_ORIGINS: 허용할 웹 주소와 capacitor://localhost
- VITE_API_BASE_URL: 아이폰 앱에서 사용할 HTTPS 분석 서버 주소. 아이폰 배포용 제작 전에 설정해야 합니다.

기존 서버는 예전 응답 형식을 사용하므로 새 앱의 AI 분석에는 업데이트된 서버가 필요합니다. 수정본은 Preview에서 실제 사진으로 확인했으며, 2026-11-23 소유자의 요청에 따라 GitHub main과 공개 앱에 반영합니다. 사진은 요청당 4MB 이하, 긴 변 1600px 이하로 제한합니다. AI 응답은 앱과 서버 양쪽에서 검사합니다. CORS는 비용 남용 방지 수단이 아니므로 공개 운영 전에 서버 측 요청 횟수 제한과 지출 한도를 설정해야 합니다.

## 공유 보상과 AI 영상 (2026-11-23)

- 공유 기록은 현재 기기의 브라우저에 저장하며 편집 화면·보관함·영상 공유가 함께 사용합니다. 1~3회에 흔들흔들·샤방샤방·아련아련 GIF, 4~6회에 봄날·가을·필름 프레임이 열립니다.
- 파일은 공유 버튼을 누르기 전에 준비하여 모바일 브라우저의 공유 동작을 유지합니다. 공유 취소·기기 저장은 보상으로 계산하지 않습니다.
- 파일 공유를 지원하지 않는 컴퓨터는 다운로드 후 친구에게 직접 전송하고 “친구에게 보냈어요”를 눌러 확인합니다. 상대방 수신 여부를 검증하는 기능은 아닙니다. 로그인·기기 간 보상 동기화는 없습니다.
- “AI 영상 만들기”에서 편집한 네 사진과 별도 동의를 받아 HeyGen Video 1로 5초·480p 영상을 만듭니다. 완성 영상을 기기에 저장하거나 GIF와 같은 보관함에 보관하고 공유할 수 있습니다.
- 서버에 HEYGEN_API_KEY와 VIDEO_TEST_CODE를 등록해야 합니다. API 키는 videos:write·videos:read 권한과 유료 API 잔액이 필요합니다. 테스트 코드는 운영자가 사무실 테스터에게 별도로 전달합니다. 둘 중 하나라도 없으면 제작을 시작하지 않습니다.
- 서버는 영상의 생성 요청 ID를 HeyGen Idempotency-Key로 보내 연결 재시도의 중복 제작을 방지합니다. 같은 탭의 sessionStorage에는 사진 대신 요청 지문·ID와 해당 영상만 조회하는 서명 토큰을 저장합니다. 토큰은 7일 동안 유효하며, 브라우저를 완전히 닫으면 기록이 사라질 수 있으므로 완성 후 저장해주세요.
- HeyGen은 참고 사진과 영상을 작업 공간에 보관할 수 있습니다. 사진 속 인물의 동의를 받고 이용하고, 삭제 요청은 운영자의 HeyGen 작업 공간에서 처리합니다.
- 공식 연동 문서: https://developers.heygen.com/docs/models/heygen-video

영상 파일은 외부 저장소의 브라우저 접근 제한을 피하기 위해 해당 영상의 서명 토큰으로 앱 서버에서 받습니다. 현재 앱 내 파일 수신은 4MB 이하이며, 더 큰 영상은 “영상 원본 열기”에서 직접 저장할 수 있습니다.

영상 종류는 “기본 · 인물 그대로”가 기본값이며, “귀여운 강아지 변신”을 추가로 선택할 수 있습니다. 두 종류 모두 네 사진을 참고해 원래 포즈 → 작은 손인사 → 하트 순서의 5초 영상을 요청합니다. 동물 종류는 표정·헤어스타일·옷 색을 참고하도록 요청하며, 인물 수와 좌우 배치를 유지하도록 합니다. 두 영상을 별도로 생성하므로 움직임·타이밍·캐릭터 대응은 실제 결과 확인이 필요하고 완전한 동작 일치를 보장하지 않습니다. 추가 이미지 생성 API는 사용하지 않으므로 Videos Write 권한만 사용합니다.

강아지 변신은 사람 몸에 동물 머리를 붙이는 방식 대신 몸 전체가 털·주둥이·짧은 앞발을 가진 강아지가 되도록 요청합니다. 인물별 눈매·얼굴 윤곽·표정의 느낌을 강아지 특징으로 옮기며 머리카락·사람 손·옷은 제외하고 옷 색은 목줄 등의 작은 색 단서로만 사용합니다. 인물과 닮은 느낌은 결과를 보고 사용자가 판단해야 합니다.

최신 영상 옵션은 기본 실사와 2D 펜화 애니메이션입니다. 동물 변신은 사용자의 방향 변경으로 교체했습니다. 펜화는 원본 인물의 얼굴·머리 모양·옷을 유지하도록 요청하며 가는 검은 펜선, 흰 종이 바탕, 옅은 수채색을 사용합니다. AI 결과의 얼굴·손과 동작은 원본과 달라질 수 있습니다.

모바일 감상용 기본 해상도는 실사·2D 펜화 모두 480p입니다. 현재 4:3 비율의 출력은 640×480입니다. 확대 시 선명도는 768p보다 낮을 수 있습니다.
