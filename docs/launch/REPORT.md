## AI 원가 관리

GPT-5.4 입력·캐시 입력·출력 토큰과 공급자 요청 ID, 모델, 결과 상태를 기록한다. 응답 내용·사진·동작 설명은 원가 기록에 넣지 않는다. 미제공 토큰이나 알 수 없는 요율은 0원이 아니라 미확인(null)으로 남긴다. HeyGen은 제작 ID·내부 작업 ID·모델·방식·480p·5초·상태와 무료/웰컴/초대/유료 재원을 기록한다. 모의 MP4는 실제 HeyGen 원가로 기록하지 않는다.

공식 요율에 따른 estimatedUsd, 한도 검사용 budgetReservedUsd, 청구서 확인 후 운영자가 입력하는 actualBilledUsd를 구분한다. 운영자는 사유·청구서 참조 번호와 함께 실제 청구액을 기록하며 기존 크레딧 잔액에는 영향이 없다. 지난 GPT 호출의 토큰과 실제 청구서를 소급해서 확인한 것은 아니다.

검사 중 개발 서버 자동 새로고침과 겹친 브라우저 실패는 코드 변경을 멈춘 재검사에서 모두 통과했고, 만료 데이터 삭제 검사를 추가한 최종 5개도 통과했다.
