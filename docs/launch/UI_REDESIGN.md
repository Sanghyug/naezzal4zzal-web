# 로그인·내 크레딧 디자인 적용 — 2026-11-24

승인된 UI_Redesign_Handoff의 두 이미지를 기준으로 기존 LaunchAccount 경계 안에서 구현했다.

## 구현

- 크림 분홍 배경, 분홍 로고, 둥근 제목, 독립된 실사/펜화 대표 그림, 가입 선물 티켓, 노란 카카오 버튼.
- 실제 장부 잔액·예약 크레딧·총 보유 티켓, 충전 카드, 연보라 초대 카드, 내 영상/구매/크레딧 탭.
- 문구·숫자·금액·탭·버튼은 HTML 컴포넌트다. 전체 시안 이미지를 깔거나 투명 버튼을 겹치지 않았다.
- 대표 그림만 승인 이미지의 문구 없는 영역에서 준비했다. 개인 테스트 사진은 사용하지 않았다.
- Jua/Gowun Dodum의 OFL 글꼴과 라이선스를 자체 보관한다. 필요한 글자와 ASCII를 담은 WOFF2로 줄였으며 외부 글꼴 요청 없이 표시한다. 예상하지 못한 글자는 기기 기본 글꼴로 표시한다.
- 필름·하트·종이비행기·선물은 CSS/SVG로 표현했다. 시안의 종이 질감과 손그림, 글꼴은 웹에 맞게 재현한 것이므로 원본과 픽셀 단위로 같지는 않다.
- 선착순 100명·대상 계정 한 번·마감 안내, 초대 두 조건·월 한도·링크 유효기간, 거래·탈퇴·문의 안내를 보존했다.
- 계정 화면은 스크롤되는 기존 앱 내부 대화상자다. 닫기/Escape/둘러보기는 편집 상태를 초기화하지 않는다. 키보드 포커스 가두기·복귀와 내역 탭 화살표/Home/End 이동을 지원한다.
- 기본 사진·GIF·모바일 패키징 경로, 서버 장부·RLS·비밀키·카카오 scope 처리에는 변경이 없다.

## 검증

- 브라우저 7개: 360/390/430/1280px 가로 넘침 없음, 닫기와 포커스 복귀, 탭/빈 상태, 공유 복사와 취소 구분, GIF/편집 복원, 모의 충전/미사용 취소, 영상 재다운로드, 초대 두 조건과 중복 방지.
- 자동 검사 31개 통과. launch 빌드·기존 기본 빌드·lint 통과.
- 실제 Supabase 장부 읽기 전용 확인: 회원 1명, 가입 선물 1건, 중복 가입 선물 0명, 사용 가능 5크레딧. 원격 회원/잔액/내역을 생성·초기화·변경하지 않았다.
- 기존 실제 카카오 로그인·재로그인 후 5 유지 결과는 소유자의 핸드오프에 기록된 결과다. 이번에는 실제 계정 재로그인을 대신 수행하지 않았으며, 실제 최종 인가 URL의 빈 scope와 정상 카카오 로그인 화면 도달을 별도로 검사했다.
- 실제 휴대폰/카카오톡 앱에서 이번 디자인을 재검사하지는 않았다.
- 충전·영상 기능 검사는 격리된 로컬 모의 환경에서 수행했다. 실결제·유료 AI 호출 없음.
