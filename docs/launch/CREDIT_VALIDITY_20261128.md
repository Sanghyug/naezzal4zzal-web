# 신규 유료 크레딧 사용기간 — 2026-11-28

상혁님이 토스 신청 과정에서 신규 유료 크레딧의 사용기간을 **결제일부터 1년(12개월)**으로 승인했다. 기존 지급분에는 소급 적용하지 않는다. 코드와 상품·결제·환불 안내를 결제 준비 브랜치에 반영했으며, 운영 배포 및 실결제 활성화는 아직 하지 않았다.

## 적용 범위와 계산

- 가격/수량: 10크레딧 3,900원. 신규 주문 생성 시 `paid-12-months-v1` 정책 버전을 저장한다.
- 시작: 서버가 토스에서 확인한 `approvedAt`. 주문 생성 시각이나 뒤늦은 웹훅 수신 시각으로 기한을 계산하지 않는다. 승인 시각이 누락되거나 유효하지 않으면 재확인 대상으로 남기고 크레딧을 지급하지 않는다.
- 종료: 한국시간으로 12개월 뒤 같은 시각. 다음 해 같은 날짜가 없는 2월 29일은 2월 28일 같은 시각으로 계산한다. 종료 시각부터 새 제작에 사용할 수 없다.
- 기존 구매·지급분 및 정책 전 이미 생성된 주문은 원래 조건을 유지한다. 무료 선물/초대/보상에 만료기간을 새로 붙이지 않는다. 기존 DB를 일괄 변경하는 마이그레이션이 없다.
- 추가 구매와 승인 재처리는 앞선 구매의 종료 시각을 연장하지 않는다. 무료분 우선 차감 정책은 유지하고, 유료분 사이에서는 사용기한이 가까운 묶음부터 사용한다.

## 잔액·제작·환불

- 매번 잔액 조회와 서버 제작 예약 시 기한을 확인한다. 예약 작업이나 만료 크론 실행 여부에 의존하지 않는다.
- 기한 종료분은 사용 가능 잔액에서 제외하지만, 원장 잔액/구매 기록은 삭제하지 않는다. 총 보유량과 종료된 수량을 구분해서 표시한다.
- 종료 전에 예약한 제작은 이후에도 정상 완료할 수 있다. 실패하면 예약을 복구하되 원래 기한을 바꾸지 않는다. 이미 종료된 복구분도 잔액과 환불 요청 경로를 유지한다.
- 전액 미사용이고 예약되지 않은 구매의 취소 요청은 기한 종료 후에도 막지 않는다. PG 취소가 불가능하거나 일부 사용한 경우 문의 경로를 제공한다. **부분 환불액·PG 취소 가능 기간 이후의 지급 방법은 별도 확정 대상**이다.
- 만료만으로 주문을 취소 처리하거나 환불 완료로 표시하지 않는다. 남은 유료 잔액은 기존 탈퇴 전 환불 확인 조건에 포함된다.

## 검증

- 자동 검사 82건 통과, 타입 검사와 Vite 운영 빌드 통과.
- 사용기간 신규 검사 10건: 윤년/한국시간 경계, 늦은 승인 복구, 중복 승인, 잘못된 승인 시각, 기존 주문/무료분 보존, 종료 직전·정각 예약, 종료 후 성공/실패 정산, 유료 묶음별 차감, 새 구매와 기존 기한 독립, SQLite 재시작/동시 요청, 종료 후 잔액·취소·탈퇴 보호.
- 토스 실상점 테스트, 모바일 브라우저 화면 검증, 운영 배포는 미완료다. 실제 고객 잔액·원격 DB·결제 설정은 변경하지 않았다.

## 판매 전 확인

- 토스 신청서의 서비스 제공기간은 12개월. 실제 계약에서 크레딧 서비스의 제공기간·업종·맞춤 영상 생성의 주문제작 해당 여부를 확인한다.
- 만료 전 통지 수단/횟수 및 연장·기간 종료 후 환불 기준은 적용 법규와 계약에 맞춰 확정하고 시험한다. 이번 변경은 통지 발송이나 자동 부분 환불을 구현하지 않는다.
- 공정위의 신유형 상품권 안내는 **사용기간 종료와 환불권 소멸을 동일하게 처리하지 않아야 한다는 검토 근거**로 참고했다. 포짤의 법적 상품 분류가 확정되었다는 뜻은 아니다. 환불 비율이나 법정 소멸시효를 임의로 코드에 고정하지 않았다.
