## 이번 코드 보강

1. **결제 알림 인증:** `/api/payments-webhook`에서 원본 요청의 HMAC 서명과 5분 시간차를 검증한다. 여러 서명을 허용하고 인증 실패 시 DB를 열지 않는다. 64 KiB 크기 제한을 둔다. 기존 서명 없는 `action=webhook`는 HTTP 410으로 폐쇄한다.
2. **결제 상태 재조회:** 알림에 든 금액·승인 상태·결제 키를 믿지 않고, 저장한 주문과 키로 토스를 재조회한다. 실패·만료는 실패로 정리하고 대기는 충전하지 않는다. 중복 알림으로 10크레딧을 반복 지급하지 않는다.
3. **취소 불일치 처리:** 토스 관리자 화면의 부분 취소나 이미 사용된 구매의 전액 취소가 감지되면 남은 해당 구매 크레딧을 잠그고 운영자 확인 상태로 보낸다. 자동으로 환불액을 계산하거나 사용 이력을 지우지 않는다. 운영자의 수동 정산 절차는 출시 전 추가 구현/확정 대상이다.
4. **시험 장부 분리:** 토스 테스트에는 `test-payments-...` 전용 장부를 강제한다. 공식 도메인 장부, Production 배포, 실제 AI 호출과 결합할 수 없다.
5. **구매 화면:** 확인 중인 기존 주문을 새 결제창으로 다시 열지 않는다. 실결제 주문 생성 시 AI 이용이 허용된 계정인지도 검사한다.
6. **사진 안내 정합성:** 최신 기준 사진 선택 기능에 맞게 ‘첫 사진’ 전송 안내를 ‘네 사진 중 선택한 기준 사진’으로 수정했다.
